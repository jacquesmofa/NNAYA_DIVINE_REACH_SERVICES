# Nnaya Divine Reach Services (NDRS)

## 1. Project Description
Flagship website for a Brampton-based not-for-profit serving children, youth, adults, seniors, families and newcomers. Tagline: Supporting Growth, Inspiring Change. Signature program: Igbo Roots & Generations. Audience: families seeking support, funders, municipalities, schools, employers, partners.
